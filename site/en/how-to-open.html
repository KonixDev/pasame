How to open Pasame

The first time, Windows and Mac hold Pasame back because it's new and not yet verified by Microsoft or Apple. That's normal and you only do it once: after that it opens with no warnings.

Go to: Mac · Windows · Linux

On Mac

Two parts: macOS blocks it the first time, and you allow it in Settings. It takes a minute.

  1. Install it. Open Pasame-macOS.dmg (it's in Downloads). In the window that appears, drag the Pasame icon onto the Applications folder.
  2. Open it once. Open Pasame from the Applications folder. macOS shows a warning saying it couldn't verify it, with two buttons. Click Done.

    Don't click the other button (Move to Trash): it deletes the app and you'll have to download it again.

  3. Open Settings. Apple menu (top left) → System Settings → in the left column, Privacy & Security.
  4. Allow it. Scroll to the bottom, to the Security part. You'll see a message that names Pasame and says it was blocked. Next to it, click Open Anyway.

    Not there? That button only shows up for a while after step 2. Open Pasame again, click Done and come back to this screen.

  5. Confirm. Enter your Mac password (or use Touch ID).
  6. Last warning. A notice about Pasame appears again: now click Open Anyway.

Done. A browser tab opens with Pasame: that tab is the app. It doesn't show up in the Dock, on purpose. From now on you open it like any other app, with no warnings.

Did all of that and it still won't open?

Open Terminal (Applications → Utilities → Terminal), paste this line and press Return:

xattr -dr com.apple.quarantine /Applications/Pasame.app

Then open Pasame again. That line removes the “downloaded from the internet” mark that makes macOS block it.

On Windows

  1. Open it. Double-click Pasame-Windows.exe (it's in Downloads).
  2. Blue “Windows protected your PC” screen. Click the More info text (below the message; don't click “Don't run”).
  3. A new button appears: click Run anyway.
  4. “Windows Defender Firewall” window. If it appears, click Allow access. It lets the phone see your computer; if you click Cancel, the phone won't be able to connect.

Done. A browser tab opens with Pasame. Next time it opens right away.

On Linux

On Ubuntu or Debian, double-click the .deb (or sudo apt install ./pasame_*.deb) and look for Pasame in your app menu. With the .tar.gz: extract it and run ./pasame.

On the phone

Nothing to install. Point the camera at the code shown on the computer and tap the notice that appears.
